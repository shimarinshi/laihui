# Demo 功能与边界

| 模块 | 当前可以体验 | 尚未实现 |
| --- | --- | --- |
| 发现 | 标签筛选、搜索、帖子详情、对话与复盘 | 真实推荐、服务器检索 |
| 社交 | 本页点赞、收藏、评论、关注 | 跨设备保存、真实通知 |
| 分享 | 粘贴或导入 Markdown/TXT、标签、预览、编辑与发布 | 服务端上传、账号与审核 |
| 隐私检查 | 常见大陆手机号和邮箱的规则替换、人工编辑 | 全面脱敏、附件审查、真实 AI 审核 |
| 复用 | 下载对话文档、生成给自己 AI 的参考文本 | 自动调用外部 Agent、模型训练 |
| Skill | 文件内容、使用说明、文本下载 | 执行 Skill、依赖安装与安全审计 |
| 求助与共创 | 创建活动、提交思路、图片或音频本地预览 | 多用户协作、附件云存储 |
| 互动对话 | 预设主持回复、私密草稿、转入分享流程 | 真实模型、保密谜底、多人游戏 |
| 收益 | 产品方向说明 | 付费、结算、授权交易 |

所有输入保存在当前页面内存，刷新会丢失。不要把它当作笔记存储或真正的私密聊天工具，也不要使用真实敏感资料测试。

对话导入支持 `.md`、`.txt`，文件大小上限 12 MB，文本长度上限 10 万字符。创作附件支持图片或音频的本地预览。其他上传入口以页面提示为准；这些限制只是原型限制。

「仅自己可见」在这里表示当前页面里的本地流程，不是服务端权限控制。案件背景和回复逻辑在前端源码中，不能真正隐藏答案。生产版本需要独立服务端处理这些内容。

普通静态服务即可运行。应用采用 URL hash 切换页面，不需要服务器路由重写。复制到剪贴板受浏览器安全上下文和权限限制，建议使用 localhost 或 HTTPS。
