# 来回 Demo 新版口播

采用用户确认的完整讲稿，标题、操作提示和改动说明不参与配音。沿用晓晓女声及已录制的网页操作素材，按新旁白重排并调整画面播放速度；字幕依据逐词时间生成。

## 00:00 开场：为什么想到做这个

我们跟 Agent 的聊天记录，其实是很私人的东西，也很有价值。但最近大家也看到了，有些 AI 平台会偷偷拿走用户的对话，根本不打招呼。那与其被动地被人拿走、被人用，为什么不自己主动分享出来，还能换点人气和收益呢？而且以后，小红书上那种图文教程可能会越来越少——大家遇到问题，第一反应都是去问 Agent。但问 Agent 也有门槛，你提问的方式不对，或者模型本身能力不够，给你的答案可能就是错的。那如果有人已经把这件事搞定了，把他跟 Agent 来回拉扯的那段对话，脱敏之后分享出来，你直接拿去贴给自己的 Agent 参考，是不是效率高多了？不光是解决问题，大家平时用 Agent 讨论观点、碰撞想法，这些内容分享出来，本身也有社交的价值，还有很多可以拓展的玩法。这就是我最开始想做这个东西的原因。

## 01:08 为什么对话记录会越来越有用

那你可能会问，聊天记录有什么好看的？你想啊，现在已经有人用 vibe coding 做网站、做游戏了。有什么需求，跟 Agent 说一声，它做出来，你试一下，觉得不对，再让它改。以后可能越来越多的事都是这么完成的——剪个视频，做段音乐，或者解决工作里的一个问题。那这时候，我想教别人怎么做，还需要重新截十几张图、写一篇教程吗？我直接把自己跟 Agent 把这件事做成的那段对话发出来，不就行了？我最开始怎么提的需求，中间出了什么问题，试过哪些办法，最后怎么弄好的，全都在里面。所以我觉得，以后有一部分教程，可能就直接变成了跟 Agent 解决问题的交互记录。你想学的东西，别人说不定已经跟他的 Agent 一起做过一遍了。

## 02:08 别人拿到以后，可以怎么用

而且，你不一定要自己从头读完。比如你也想做一个类似的网站，就可以把这段对话丢给你的 Agent，跟它说：“你看看他是怎么做的。我想做的跟他有点不一样，这几个地方帮我改一下。”或者你电脑出了个问题，折腾半天没解决，刚好有人分享过类似的经历。你就可以拿给自己的 Agent，让它参考这个过程，再看看你的情况。当然，不是拿过来就一定能成。但别人已经踩过的坑，你和你的 Agent 至少有机会少踩一遍。你还可以回来评论一句：“我按这个试了，但卡在这里了。”后来解决的人再补一句。这样，这段经验就能接着往下积累。

## 02:59 看别人怎么思考，怎么学会一件事

还有一种内容，我觉得也特别值得看。比如一个很厉害的人，我就好奇，他平时到底怎么用 AI？同样一个问题，为什么他能想到这么问？AI 给了一大段回答，看着挺有道理，他为什么一眼就觉得不对？我想看他怎么追问、怎么判断、怎么把自己的经验加进去。学习也是一样。比如我想学剪视频，我可能就想找一个跟我一样、从来没剪过的人，看看他是怎么一点点学会的。他哪里没听懂，问了什么，为什么第一次做出来不对——这些地方，我可能也会卡住啊。还有一些关于生活、工作、人生选择的对话。你聊完以后觉得，诶，这个角度以前真没想过，也可以分享出来。别人看完，可能受到启发，也可能有不同意见，那大家就接着聊。

## 03:59 怎么分享，也怎么给自己复盘

所以在这里，我想让大家可以直接上传对话，再补两句自己的话。比如你当时想解决什么，最后解决了没有，有哪一步特别有用。也可以说：“这次没做成，有没有人知道问题出在哪？”既是给自己做个复盘，也给后来的人一个参考。打上标签，选一段适合预览的内容，再检查一下有没有姓名、联系方式，或者不该公开的东西。平台可以帮着找，但发布前还是得自己看一遍。你不需要为了发一个帖子，重新写一篇特别完整的教程。有一段确实帮到你的经历，就可以先分享出来。

## 04:44 找经验、求助，也可以一起做东西

反过来，你也可以先来找。“有没有人用 AI 准备过这个考试？想看看你是怎么学的。”“我最近在改简历，有没有人愿意分享一下，自己跟 AI 来回改的过程？”如果你已经整理好了一个 Skill，也可以传上来，顺便教一下怎么装、怎么用，给个实际例子。别人拿回去就更容易上手试。还有，你可以只是有一个想法。比如我想做个游戏，但我只想好了玩法；或者我哼了一段旋律，觉得还不错，但不知道怎么继续。那我能不能发出来，问问有没有人感兴趣，一起用 Agent 做一下？你试一版，我试一版，大家边做边提建议。最后做出了什么，也能把过程留下来，让其他人接着改。我觉得这种交流就挺有意思的。

## 05:42 互动玩法：让用户自己发挥

再比如这里，我放了一个破案的例子。设计的人把案件逻辑、人物关系、线索先写好，让 AI 按这个背景跟玩家对话。其他人就可以通过提问，一点点把事情弄清楚。玩完之后，还能选择把自己的过程发出来。你看看别人怎么问的，可能会觉得：“这个问题我怎么就没想到？”但破案只是一个例子，不是说这个平台就是拿来玩破案的。你可以设计别的游戏，出一个挑战，或者发一个实际问题，让大家各自用 AI 试试，再一起看结果。我也想看看，大家自己会在上面搞出什么花样。

## 06:28 以后想怎么做

现在这个还是 Demo，先让大家看看这个想法。真正的模型、收益分配这些，还没有接进来。后面我想把模型也放进来，让大家直接在这里聊、在这里做。聊完以后，自己决定要不要分享、分享哪一段，留给自己也完全可以。收益这件事，我也想继续试。比如有人愿意为你整理的经验付费，或者公司想使用你的对话内容，那就把用途说清楚，经过你的同意，再谈授权和分成。包括能不能根据内容实际帮到了多少人，让分享的人得到一些回报——这些都还需要慢慢想，不能现在就说发了有浏览量就一定能赚钱。但最开始那个想法我还是想保留：既然我们贡献的经验有价值，那我们自己也应该有机会从中受益。

## 07:26 邀请大家提建议

所以我先把它做出来了，链接会放在简介里，大家可以自己点进去玩一下。你会愿意分享自己跟 AI 的哪一段对话？或者，你最想找什么样的经历来看？也欢迎直接说你觉得哪里没用、哪里还差点意思，我想听听真实的建议。名字现在暂时叫“来回”，还没定，你们有更好的也帮我想想。有兴趣一起做的可以联系我。你觉得这个想法不错，想自己做一个，也可以啊。我也挺想看看，大家会把它做成什么样。
